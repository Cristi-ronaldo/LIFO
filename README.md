# LIFO
Es la regla que usan las pilas. Piensa en una pila de platos: el ultimo plato que pones encima es el primero que agarras cuando vas a lavar. El que pusiste primero queda hasta abajo y sale de ultimo.  En la compu pasa igual, por ejemplo en el boton de deshacer: cada cosa que haces se va apilando y cuando deshaces quitas la ultima, no la primera..
